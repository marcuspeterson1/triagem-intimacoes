# Triagem de Intimações

Ferramenta grátis do canal **Escritório Automatizado**. Cola sua OAB, recebe a tabela: que peça
cada intimação pede, qual o prazo (com a base legal), e o que buscar nos autos antes de escrever.

Roda inteiro no navegador de quem usa — sem servidor, sem backend, sem instalar nada. Consulta
direto a API pública do DJEN.
